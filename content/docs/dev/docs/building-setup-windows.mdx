# Setup the Build Environment on Windows


There are two options for building on Windows: Windows Subsystem for Linux (WSL) or Cygwin. New developers should use WSL as it offers faster compilation times, greater compatibility, and a larger support base from other developers.


## Setup for building with waf using WSL (Windows 10 and 11 only)


#. Install WSL as described [here](https://docs.microsoft.com/en-us/windows/wsl/install)
#. If Windows 10 [follow these instructions](/docs/dev/docs/building-setup-windows10_new), if Windows 11 [follow these instructions](/docs/dev/docs/building-setup-windows11).
#. (optional, if you wish to use VSCode editor) [Setup VSCode as described here](/docs/dev/docs/editing-the-code-with-vscode)


## Setup for building with waf using Cygwin


<Callout type="info">
Cygwin is not recommended for new developers. However, building using Cygwin is sometimes useful if you need to compile SITL binaries for Windows. However, you can create Windows SITL executables without using Cygwin, following the instructions given [here](/docs/dev/docs/sitl-with-realflight).
</Callout>

#. [Install Cygwin as described here](/docs/dev/docs/building-setup-windows-cygwin)
#. [Setup Eclipse as described here](/docs/dev/docs/building-setup-windows-eclipse) (optional)
