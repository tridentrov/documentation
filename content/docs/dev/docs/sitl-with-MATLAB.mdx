# MATLAB and Simulink


All Matlab and Simulink functions rely on the [TCP/UDP/IP Toolbox 2.0.6](https://www.mathworks.com/matlabcentral/fileexchange/345-tcp-udp-ip-toolbox-2-0-6). 
A modified version of the toolbox is provided in the ArduPilot [repository](https://github.com/ArduPilot/ardupilot/tree/master/libraries/SITL/examples/JSON/MATLAB/tcp_udp_ip_2.0.6).
The toolbox is compiled into a [MEX file](https://www.mathworks.com/help/matlab/call-mex-file-functions.html) allowing for fast connection speeds,
also removing the need for a licence for the official TCP/UDP tools. Pre-built MEX files are provided for Windows and Linux however it may be necessary
to compile locally. The [basic MATLAB Simulation copter](https://github.com/ArduPilot/ardupilot/blob/master/libraries/SITL/examples/JSON/MATLAB/Copter/SIM_multicopter.m)
example will try to do this if no MEX file is found. This should be run before trying the other examples.
