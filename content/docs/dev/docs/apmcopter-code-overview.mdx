# Code Overview (Copter)


The [code](https://github.com/ArduPilot/ardupilot) is made up
of [the main Copter code](https://github.com/ArduPilot/ardupilot/tree/master/ArduCopter) which
resides in its own directory, and [the libraries](https://github.com/ArduPilot/ardupilot/tree/master/libraries) which
are shared with Plane and Rover.
