# ESP32 Based Autopilot


<Callout type="info">
this code and development is experimental. No OEM has produced an ArduPilot compatible autopilot based on the ESP32. This code requires that sensors be attached to an ESP32 board or making a custom PCB. Only the 'classic' ESP32 is currently targeted but work on ESP32S3 in in progress.
</Callout>

<Callout type="info">
Monitor the [ArduPilot Discord ESP32 channel](https://discord.com/channels/674039678562861068/777475957476032523) for updates and developments.
</Callout>
