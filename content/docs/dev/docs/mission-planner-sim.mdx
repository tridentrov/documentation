# Simulation Within Mission Planner


Mission Planner provides a means to run a simulation using the native [SITL](/docs/dev/docs/sitl-simulator-software-in-the-loop) physics models, but within the Windows environment.

See: [Mission Planner Simulation](https://ardupilot.org/planner/docs/mission-planner-simulation.html)
