# Editing the code with NotePad++


NotePad++ can be downloaded from [here](https://notepad-plus-plus.org/).

# Use Project Panels to organise lots of files


![NotePad_ProjectPanel](/docs/dev/images/NotePad_ProjectPanel.png)
# Use spaces instead of tabs


Under Settings, Preference, Language Menu/Tab Settings ensure the
"Replace [tab] by space" checkbox is checked.

![EditingTheCode_NotePad++](/docs/dev/images/EditingTheCode_NotePad++.png)
