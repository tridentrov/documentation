## Messages

### LOWEHEISER_GOV_EFI (ID 10151)

Composite EFI and Governor data from Loweheiser equipment. This message is created by the EFI unit based on its own data and data received from a governor attached to that EFI unit.

| --- | --- | --- |
| `volt_batt` | `float` | Generator Battery voltage. |
| `curr_batt` | `float` | Generator Battery current. |
| `curr_gen` | `float` | Current being produced by generator. |
| `curr_rot` | `float` | Load current being consumed by the UAV (sum of curr_gen and curr_batt) |
| `fuel_level` | `float` | Generator fuel remaining in litres. |
| `throttle` | `float` | Throttle Output. |
| `runtime` | `uint32_t` | Seconds this generator has run since it was rebooted. |

| `rectifier_temp` | `float` | The Temperature of the rectifier. |
| `generator_temp` | `float` | The temperature of the mechanical motor, fuel cell core or generator. |

| `efi_rpm` | `float` | Motor RPM. |

| `efi_fuel_flow` | `float` | Fuel flow rate in litres/hour. |
