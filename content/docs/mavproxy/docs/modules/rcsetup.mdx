# RC Setup


```bash
module load rcsetup
```

The rcsetup module provides a method to calibrate the RC min/max/centre value.

```bash
rccal N
```

Start/stop the rc calibration process for the first ``N`` channels. Omit ``N`` to 
calibrate all available channels.
